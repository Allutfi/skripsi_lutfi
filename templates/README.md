# templates/

Taruh di sini berkas yang kamu perlukan sebagai bahan gabungan, misalnya:
- Halaman sampul, lembar pengesahan, dan lembar persetujuan proposal (diunduh dari SIAKAD:
  https://siakadv2.itbwigalumajang.ac.id) — bergantung akun masing-masing mahasiswa.
- Template .docx milik kampus/prodi bila ada.

Skrip `scripts/buat_docx.py` hanya membuat isi proposal (Bab 1–3 + Daftar Pustaka).
Gabungkan sampul/pengesahan dan bagian awal (Kata Pengantar, Daftar Isi, Daftar Tabel, Daftar Gambar) secara manual di Word.
